# 🌤️ Abeokuta 7-Day Weather Forecast
### Multi-Step Temperature Forecasting with GRU (PyTorch) + Streamlit Dashboard

---

## Overview

This project builds and deploys a deep learning model that forecasts the **next 7 days of daily temperature** for **Abeokuta, Ogun State, Nigeria**, using 9 years of historical weather data (2017–2026).

Abeokuta has a tropical climate with a distinct **wet season (April–October)** and **dry season (November–March)**. This seasonal structure makes temperature patterns learnable from historical data — which this project exploits using a Gated Recurrent Unit (GRU) neural network.

The project has two components:

- **`Forecasting_Abeokuta_Weather_Portfolio.ipynb`** — the full research notebook covering data collection, EDA, model training, and evaluation.
- **`app.py`** — a Streamlit web app that loads the trained model and serves a live 7-day forecast dashboard.

## How It Works

### 1. Data Collection
Historical daily weather data is fetched from the [Visual Crossing Weather API](https://www.visualcrossing.com/), one year at a time, to stay within free-tier limits. Each yearly file is cached locally so downloads are never repeated. The data includes temperature (°F), humidity, precipitation, wind speed, and weather conditions.

### 2. Exploratory Data Analysis (EDA)
The notebook visualises 9 years of temperature data, including daily values, 30-day rolling means, and seasonal decomposition — confirming the clear wet/dry seasonal rhythm expected in Abeokuta.

### 3. Preprocessing
- Columns used: `datetime`, `temp`, `humidity`, `precip`, `windspeed`, `conditions`
- Temperature is scaled using `MinMaxScaler` (fitted on the training set only — no data leakage)
- A **sliding window** of 30 days is used as input to predict the next 7 days

### 4. Baseline Models
Two simple baselines were established before training the GRU:

| Model | Mean MAE (°F) | Mean RMSE (°F) |
|---|:---:|:---:|
| Persistence (repeat last value) | 2.615 | 3.295 |
| 30-Day Rolling Mean | 2.222 | 2.823 |

### 5. GRU Model

A Gated Recurrent Unit (GRU) network with **direct multi-step output** — predicting all 7 days simultaneously rather than feeding predictions back as inputs. This prevents error accumulation across horizons.

**Architecture:**

| Parameter | Value |
|---|---|
| Input size | 1 (temperature only) |
| Hidden size | 64 |
| GRU layers | 1 |
| Output | 7 (one per forecast day) |
| Lookback window | 30 days |

### 6. Results

| Model | Mean MAE (°F) | Mean RMSE (°F) | Beat Baseline? |
|---|:---:|:---:|:---:|
| Persistence | 2.615 | 3.295 | — |
| Mean-30 | 2.222 | 2.823 | ✅ |
| **GRU (Direct)** | **2.164** | **2.761** | ✅ Best |

The GRU beat both baselines on every horizon. No overfitting was observed — validation loss tracked training loss closely throughout.

## Streamlit Dashboard (`app.py`)

The dashboard loads the trained model and the most recent 60 days of CSV data to produce a live forecast. It displays:

- **Current conditions** — last observed temperature, humidity, and wind speed
- **Season indicator** — Harmattan, Wet Season, etc., based on the current month
- **7-day forecast cards** — colour-coded by temperature range (cool → extreme heat)
- **Temperature trend chart** — line chart of the 7-day forecast
- **Historical context** — last 30 days as an expandable chart
- **Recommendations** — contextual health, farming, travel, and energy tips based on the forecast and season

## Setup & Installation

### Prerequisites
- Python 3.9 or higher
- A Visual Crossing API key (free tier available at [visualcrossing.com](https://www.visualcrossing.com/))

### Install Dependencies

```bash
pip install torch streamlit pandas numpy scikit-learn requests matplotlib
```

### Step 1 — Collect Data

Open the notebook and run the data collection cells. Your API key is passed directly to the `download_weather_data()` function. CSVs will be saved to the `weather_data/` folder.

### Step 2 — Train the Model

Run all notebook cells in order. The final cell saves the trained model weights:

```python
torch.save(GRU_model.state_dict(), "GRU_model.pth")
```

### Step 3 — Configure the App

Open `app.py` and update the two path constants at the top to match your local setup:

```python
MODEL_PATH  = "path/to/GRU_model.pth"
DATA_FOLDER = "path/to/weather_data"
```

### Step 4 — Launch the Dashboard

```bash
streamlit run app.py
```

The dashboard will open in your browser at `http://localhost:8501`.

## Design Decisions

| Decision | Choice | Reason |
|---|---|---|
| Forecasting strategy | Direct multi-step | No error accumulation across horizons |
| Architecture | GRU | Lighter than LSTM, comparable performance on short univariate series |
| Input window | 30 days | Captures one full seasonal month of context |
| Forecast horizon | 7 days | Practically useful for weekly planning |
| Scaling | MinMaxScaler (fit on train only) | Prevents data leakage |
| Temperature unit | °F (model), °C (display) | API returns °F; dashboard converts for local readability |
